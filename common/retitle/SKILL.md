---
name: retitle
description: 按统一格式批量重命名当前项目下的对话标题，让侧边栏一眼看出每个对话的日期、类型和主题。当用户要求整理、规范或重命名对话（会话、线程）标题时使用。
---

只更改对话标题，绝不触及项目名称、对话内容、项目归属、顺序、置顶状态和归档状态。

用所在工具提供的会话管理能力（如 Codex 桌面版的线程工具、Claude Code 桌面版的会话管理工具）列出当前项目下的对话，读取每个对话的创建时间和内容。工具没有这类能力时，直接说明并停止，不要猜测或绕路。用户指定范围时只处理该范围；未指定时处理当前项目下的全部对话。

标题格式为 `MMDD｜TYPE｜Topic`，分隔符是全角竖线：

- 日期取对话的创建时间，换算为 Asia/Shanghai 时区后写成四位月日。不要使用最后更新时间。
- TYPE 必须是下列八种之一。默认使用英文代码，只有用户要求中文时才使用中文标签；一次运行中所有标题的 TYPE 使用同一种语言，绝不混用。

| 英文代码 | 中文标签 | 含义 |
| --- | --- | --- |
| FEA | 功能 | 新功能 |
| DES | 设计 | 设计 |
| FIX | 修复 | 修复缺陷 |
| OPT | 优化 | 优化 |
| REL | 发布 | 发布 |
| EXP | 探索 | 探索 |
| DOC | 文档 | 文档 |
| RES | 研究 | 研究 |

- Topic 概括对话的实际内容，简短且具体，不重复项目名称。
- 无法辨别主题的对话保留原标题，不要猜测。

示例（英文，默认）：

| Before | After |
| --- | --- |
| Improve batch text display | 0903｜OPT｜Batch text display |
| New feature discussion | 0901｜DES｜UI alignment check |

示例（中文，按要求）：

| Before | After |
| --- | --- |
| 优化批次文字显示 | 0903｜优化｜批次文字显示 |
| 提交代码到 GitHub | 0813｜发布｜提交代码到GitHub |

在进行任何更改之前，只输出一张两列表格，表头固定为 `| Before | After |`，然后等待用户确认。确认后执行重命名，只报告结果。
