---
name: explain
description: 把指定文档转换成 HTML 讲解页面，帮助用户轻松读懂内容与设计理由。当用户读某份文档有阻力、不理解其中概念，或想以更直观的方式阅读时使用。
---

确定要讲解的目标文档：用户指定时按指定执行；未指定时，取本次对话中最近生成或讨论的文档。

读取目标文档；若属于 specs/ 下的工作流文档，顺着其中的引用读取关联文档（如技术方案引用的功能文档 AC），确保讲解有完整上下文。

把用户当成不熟悉文中概念的人，生成分层渐进的 HTML 讲解页面：

- 开头用大图和比喻给出整体概览，图要大，字要少。
- 每个部分可展开查看详细讲解：用大白话重讲原文内容，生疏概念就地解释，并讲清设计背后的理由。
- 只讲解，不改动任何文档；发现文档本身的问题时，在对话中向用户指出。

HTML 生成到临时目录并用浏览器打开，不写入目标项目仓库；内容的唯一来源始终是 Markdown 文档，需要再看时重新生成即可。
